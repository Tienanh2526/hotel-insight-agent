# 03 — User Stories

## US-01 Upload CSV
As a user, I want to submit a CSV so I can analyze hotel reviews.
- Valid CSV accepted.
- Response reports row counts and detected columns.
- Malformed file returns actionable error.

## US-02 Inspect invalid rows
As a user, I want to know which rows need fixing.
- Issues contain row number and reason.
- Sensitive review text is not echoed unnecessarily.
- Invalid rows are not silently discarded.

## US-03 Classify reviews
As a user, I want reviews grouped by topic and sentiment.
- Labels belong to a versioned taxonomy.
- Multi-label topics supported.
- Unclear items are flagged.

## US-04 Verify evidence
As a user, I want each finding to link to exact source reviews.
- Source IDs retained.
- Quotes match source text exactly.
- Findings without evidence are flagged.

## US-05 Review report
As a manager, I want counts, denominators, caveats, and next-step suggestions.
- Counts are computed by Python.
- Missing dates do not produce trends.
- Observations are separated from hypotheses.

## US-06 API integration
As a developer, I want versioned endpoints and schemas so a frontend can be added later.
- OpenAPI docs generated by FastAPI.
- Request/response schemas are explicit.
- Automated tests cover success and failure cases.
